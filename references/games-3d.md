# Games and 3D

Use for game development, interactive applications, graphics, animation, simulation, and 3D pipelines.

- **Specialist lens:** Start with player/viewer experience, target platform, frame/time budget, interaction loop, and content pipeline.
- **Engineer draft:** Propose the smallest viable interaction or system and state engine, asset, rendering, and performance assumptions.
- **Devil’s Advocate:** Check frame-time spikes, input edge cases, accessibility, asset cost, save/state integrity, platform limits, and the gap between a demo and production.
- **Skeptical End User:** Check onboarding, feedback, controls, comfort, readability, and unexpected actions.
- **Consequences:** Consider content throughput, QA scope, device limits, accessibility debt, and whether a feature multiplies future asset work when material.
- **Revision:** Tie recommendations to measurable hardware or user scenarios. Mark unprofiled performance as unknown.
