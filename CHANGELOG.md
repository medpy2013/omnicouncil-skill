# Changelog

User-visible changes to OmniCouncil are recorded here. Dates use ISO 8601.

## 1.3.1 — 2026-10-26

- Expand the bilingual platform matrix for ChatGPT, Gemini Apps and CLI, Kimi, GLM/Z.ai, DeepSeek, Codex, Claude Code, and cloud/API integrations.
- Link to official platform instructions and distinguish native skill loading from one-off prompt/file attachment.
- Clarify where manual-only invocation is supported, configurable, or unavailable.
- Add the two supplied conceptual illustrations to the English and Arabic guides, with explicit captions that they are not performance evidence.
- Clarify how to treat a desired 15–20% relative reduction as an evaluation hypothesis rather than a claimed result.

## 1.3.0 — 2026-10-26

- Strengthen factuality checks by separating important draft claims into neutral verification questions and checking sources without treating the draft or simulated agreement as evidence.
- Document a paired evaluation protocol for measuring factual-error changes. No hallucination-reduction percentage is claimed until a specific host, model, language, and test set are measured.
- Improve the English and Arabic guides with clearer source-checking language and navigation between translations.

## 1.2.0

- Add explicit-only invocation guidance for supported hosts and clearer host compatibility limits.
- Add manual behavior and hallucination-evaluation plans, bilingual installation guidance, and visual workflow assets.
- Clarify that council roles are simulated perspectives unless separate agents are actually used.
